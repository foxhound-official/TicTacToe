# TicTacToe

Android-приложение с реализацией игры в крестики-нолики на полях 3×3 и 4×4.

Проект написан на Java с использованием Android SDK. Помимо самой игры, приложение содержит систему аккаунтов, сохранение статистики побед и поражений, настройки и поддержку русского и английского языков.

## Возможности

* Игра на поле 3×3.
* Игра на поле 4×4.
* Игра против другого человека.
* Игра против компьютера.
* Три уровня сложности компьютера:

  * Easy
  * Normal
  * Hard
* Выбор игрового символа: крестик или нолик.
* Подсчёт побед и поражений.
* Таблица статистики игрока.
* Создание пользовательского аккаунта.
* Авторизация по логину и паролю.
* Личный кабинет.
* Сохранение последнего использованного аккаунта.
* Переключение русского и английского языков.
* Настройка звука.
* Портретная ориентация интерфейса.

## Игровой процесс

Перед началом партии игрок выбирает параметры игры:

* против компьютера или другого человека;
* уровень сложности компьютера;
* размер игрового поля;
* используемый символ.

При выборе игры против человека настройки сложности компьютера и выбора символа для компьютера отключаются.

После настройки приложение запускает соответствующий игровой экран:

* `Game3x3Activity` для поля 3×3;
* `Game4x4Activity` для поля 4×4.

Победа определяется по горизонтальным, вертикальным и диагональным линиям.

Для поля 3×3 требуется собрать линию из трёх символов.

Для поля 4×4 требуется собрать линию из четырёх символов.

## Компьютерный игрок

Логика компьютера реализована в классе `ZComputerPlayer`.

Предусмотрено три уровня сложности:

### Easy

Компьютер выбирает первую доступную клетку, проходя игровое поле последовательно.

### Normal

Компьютер использует несколько вариантов обхода игрового поля:

* горизонтальный;
* обратный горизонтальный;
* вертикальный;
* обратный вертикальный.

Вариант обхода выбирается случайным образом.

### Hard

Для поля 3×3 компьютер анализирует возможные комбинации и пытается найти выигрышный или блокирующий ход.

Для поля 4×4 используется аналогичный подход с анализом линий из четырёх клеток.

Основная логика проверки состояния поля вынесена в отдельные классы:

```text
ZLogicCalculation3x3.java
ZLogicCalculation4x4.java
```

## Аккаунты

Приложение содержит простую локальную систему аккаунтов.

При создании аккаунта сохраняются:

```text
пароль
количество побед
количество поражений
```

Данные хранятся во внутреннем файловом хранилище приложения.

Имя пользователя ограничено 10 символами. Пароль также ограничен 10 символами.

После авторизации приложение сохраняет данные последнего аккаунта в `RecentAccounts.txt`, что позволяет автоматически использовать недавно выбранный аккаунт в дальнейшем.

> Система аккаунтов является локальной и учебной. Данные не передаются на сервер.

## Статистика

Для каждого аккаунта сохраняется количество:

* побед;
* поражений.

Статистика отображается в `RecordsTableActivity`.

Пользователь может открыть таблицу результатов через раздел настроек.

## Личный кабинет

`PrivateCabinetActivity` позволяет работать с данными текущего аккаунта.

Предусмотрены операции:

* просмотр данных аккаунта;
* изменение логина;
* изменение пароля;
* просмотр статистики;
* выход из аккаунта.

При изменении логина старый файл аккаунта удаляется, после чего создаётся файл с новым именем.

## Локализация

Приложение содержит два набора текстовых ресурсов:

```text
app/src/main/res/raw/russian.txt
app/src/main/res/raw/english.txt
```

Переключение языка выполняется через `SettingsActivity`.

Текущий язык хранится в объекте `MyApplication` и используется активностями для получения соответствующих строк интерфейса.

### Основные активности

`MenuActivity.java`

Главное меню приложения. Позволяет начать игру, открыть настройки или завершить работу приложения.

`PreGameActivity.java`

Экран настройки партии. Здесь выбираются противник, сложность, размер поля и игровой символ.

`Game3x3Activity.java`

Реализует игровую партию на поле 3×3.

`Game4x4Activity.java`

Реализует игровую партию на поле 4×4.

`LoginPassActivity.java`

Авторизация пользователя.

`CreateAccountActivity.java`

Создание нового локального аккаунта.

`PrivateCabinetActivity.java`

Личный кабинет пользователя.

`RecordsTableActivity.java`

Отображение количества побед и поражений.

`SettingsActivity.java`

Настройки приложения, включая язык, звук, статистику и личный кабинет.

## Особенности реализации

Проект использует локальное файловое хранилище Android для аккаунтов и статистики. Отдельной базы данных или серверной части нет.

Состояние игры передаётся между Activity через `Intent` extras.

Текст интерфейса хранится в отдельных текстовых файлах, после чего загружается в `MyApplication`.

## Ограничения

Проект является учебным Android-приложением и имеет ряд упрощений:

* аккаунты хранятся локально;
* серверной авторизации нет;
* пароль хранится непосредственно в локальном файле аккаунта;
* нет сетевой многопользовательской игры;
* статистика привязана к локальному аккаунту;
* проект использует устаревшие Android Support Libraries;
* интерфейс рассчитан на портретную ориентацию.

## Назначение

Проект представляет собой учебную реализацию мобильной игры в крестики-нолики с дополнительными возможностями работы с пользователями и локальной статистикой.

Основной интерес с точки зрения разработки представляют реализация игровых полей разных размеров, алгоритмы выбора хода компьютера, управление состоянием между Android Activity и простая система локального хранения пользовательских данных.
